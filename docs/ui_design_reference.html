设计要点

  • 全局暖米色背景，长时间使用降低眼部疲劳
  • 组件使用 4px 小圆角 + 清晰 1-2px 边框，营造轻像素感
  • 按钮按语义着色：Primary（绿）/ Success（绿）/ Danger（珊瑚红）/ Accent（琥珀）
  • 终端与日志保持暗色，但使用柔和暗灰而非纯黑
  • 状态栏分组清晰，动态消息与永久署名分区显示
